changelog — pdf2html (kmfe-pdf2html)
======================================

В разработке (feature/gui)
---------------------------
- Графический интерфейс (CustomTkinter): выбор PDF, выходной папки, диапазона страниц, номера тома
- Расширение Chrome «pdf2html Pager»: постраничный просмотр HTML-файлов с метками <!--nextpage-->
- Исправлен паттерн file:// в манифесте расширения (был неверный формат хоста)
- Заголовочный блок разбивается на H2 / параграф / H3 по признакам жирности и размера шрифта
- Мелкошрифтовые декоративные строки заголовка рендерятся как центрированные параграфы с классом heading-label
- Исправлено дублирование годовых диапазонов на титульных страницах
- Исправлено смещение сносок-sup в многозаголовочных страницах
- Исправлено извлечение JPEG-иллюстраций (rawdata → get_data())
- Продолжение цитат через границу страниц: если предыдущая страница заканчивается открытой цитатой, первые абзацы следующей страницы (мелкий шрифт) помечаются как blockquote
- Эталонный размер шрифта тела передаётся между страницами через колонтитул; устраняет ложное определение is_small на страницах, где цитата занимает большую часть объёма
- Исправлено слияние абзацев: первый абзац страницы (одна строка с отступом) не склеивается со следующим абзацем; снижен порог «короткой строки» с 60 до 25 pt
- Исправлен пропуск первого абзаца страницы: колонтитул исключается по y-координате, убрано blocks[1:]
- Стихотворные вставки (мелкий шрифт + центрирование) корректно распознаются как blockquote align=CENTER
- Заголовочная область исключается из расчёта эталонного размера шрифта; устраняет ложное is_small на страницах с крупными заголовками

v0.4 (коммит 0f4c45e)
----------------------
- Первый тегированный релиз
- Определение заголовков: ALL-CAPS центрированные строки → H2
- Определение подписей: двухколоночный блок внизу страницы
- Определение сносок: блок мелким шрифтом с маркером *, отделённый горизонтальной чертой
- Определение колонтитулов: автор + номер страницы, исключение из тела текста
- Нумерация HTML-якорей по печатному номеру книги (не PDF-странице)
- Определение цитат: мелкий шрифт → blockquote; хвост цитаты (» без «) → blockquote
- sup / sub для сносок и индексов внутри текста
- Разбивка абзацев по вертикальному зазору и отступу первой строки
- Корректная склейка строк через перенос (дефис в конце строки)
- Пресканирование для определения нумерации страниц с обратной экстраполяцией
- Поддержка диапазонов страниц (--pages 1-10, 1,3,7-9)
- Извлечение иллюстраций (LTImage → JPEG) с именованием по тому и странице
