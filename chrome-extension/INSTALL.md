# Установка расширения pdf2html Pager

Расширение показывает HTML-файлы с метками `<!--nextpage-->` постранично.

## Установка

1. Открыть в Chrome адрес: `chrome://extensions/`
2. Включить **Режим разработчика** (переключатель в правом верхнем углу)
3. Нажать кнопку **«Загрузить распакованное»**
4. Выбрать папку `chrome-extension` из этого репозитория
5. На карточке расширения нажать **«Сведения»** → включить **«Разрешить открытие локальных файлов»**

## Использование

Откройте любой сконвертированный HTML-файл в Chrome — расширение подхватит его автоматически.

- **◀ / ▶** — предыдущая / следующая страница
- **← / →** (клавиши) — то же самое
- Поле с номером страницы — ввести номер и нажать Enter для перехода

Позиция сохраняется в адресной строке (`#p5`), поэтому кнопка «Назад» в браузере работает как ожидается.

## Обновление

Если файлы расширения изменились, зайдите на `chrome://extensions/` и нажмите кнопку обновления (🔄) на карточке расширения.
